# 周期の一部を止める正弦波キャリア（r72）

modern FMのWS3・4・5・11・12・13を対象に、波形1周期の一部だけを出力する形状の
高音域を補正します。変調もフィードバックもない最終出力に限定し、
音符の時刻・ゲート長、元の低・中音域のfloat丸めを保持します。

## DC・基音・位相

fがFs/4を超えると、第2倍音以降はすべてナイキスト上限を超えます。
Fs/4〜Fs/3で、元の波形から次のDC・基音へ滑らかに移行します。
θは演算器の位相です。`d`は既存の1.7倍クリップ正弦波を半波整流した平均値です。

| 波形 | DC | 残す基音 |
| --- | --- | --- |
| WS3 | 1/π | なし |
| WS4 | 0 | 4/(3π) × cos(θ) |
| WS5 | 1/π | 4/(3π) × sin(θ) |
| WS11 | d ≈ 0.40334595618727476 | なし |
| WS12 | 0 | h × cos(θ) |
| WS13 | d | h × sin(θ) |

`a = asin(1/1.7)/2`として、
`h = 2/π × ((2×1.7/3)(1-cos³(a)+sin³(a)) + cos(a)-sin(a)) ≈ 0.53086353510404305`です。
WS4・12では余弦の位相を保つことが重要です。既存の共有正弦テーブルを1/4周期ずらして
使い、連続波形の平均値・基音係数を維持します。メーカー波形への校正や、音色間の音量調整は行いません。

元の形状は既存の`waveform_`から読み、補正域より低い出力を置き換えません。
ビブラート・MULTI・detuneを含む実際の位相増分と、r69のナイキスト抑制を使います。
新しい音別の状態やメモリ割り当ては加えません。キャッシュはr72です。

## 検証

`tools/fm-gated-sine-carrier-test.cpp`は、各波形262,144点の中点積分から独立した
DC・正弦係数・余弦係数を求めます。6波形・2レート・13周波数・5初期位相の780条件で、
低・中音域の完全一致、補正域の誤差低減、基音の振幅・位相、全8接続、変調と
フィードバックの除外、ビブラート、ピッチ変更、周期端点を確認しました。
完全移行後の最大RMS誤差は約9.68e-8でした。修正前はDC・基音の一致検査が失敗しました。

既存983素材はWAV全体が一致しました。新しい270素材では対象156素材だけが変わり、
114対照は完全一致しました。合計1253素材中1097素材が一致し、全素材の形式・
フレーム数を維持しました。メーカー音色やROMを含まない素材です。

`tools/generate-gated-sine-probes.py <新規ディレクトリ>`で270素材を再生成できます。
全8接続、低音対照、移行域、高いMULTI、変調器、フィードバック、ビブラート、
補正域をまたぐピッチ変更を含みます。

ゲート正弦波、クリップ正弦波、整流正弦波、FM位相、既存FM帯域制限、高周波ビブラート、
PCM16/JNIブリッジ、無音音符の同時発音、入力保護の9スイートがASan/UBSan付きで通過しました。
ローカルのクラウドでは`ASAN_OPTIONS=detect_leaks=0`でリーク検査を無効にしています。
Androidの3 ABIのDebug・Releaseとlintも通過しました。

移行域には折り返し成分が残ります。元の波形の校正、他の波形、低・中音域、
動的なFM変調・フィードバックと、Android実機での負荷・消費電力は引き続き別の課題です。
