# r87/r88：無音の演算器で簡約できるFM接続の折り返し低減

通常再生・プログレッシブ変換・WAV保存の自動8倍／16倍処理を、以下の限定した
接続3・4・6へ広げます。全演算器が正弦波で、実効フィードバックがない場合だけ適用します。

| 接続 | 発音中ずっと無音である条件 | 残る変調経路と混合 |
| --- | --- | --- |
| 3 | op2のアタック速度が厳密に0 | op0 → op3、係数1 |
| 4 | op1のアタック速度が厳密に0 | op2 → op3、係数1 |
| 6 | op1のアタック速度が厳密に0 | op0 + (op2 → op3)、係数0.5 |

演算器番号は0から始まります。これらは無音の枝を除くと、既存の2演算器変調と同じ形です。
密度選択には残る変調器・キャリアの組を使い、既存の保守的な側帯波上限を維持します。
音符の途中で密度を下げることはありません。

残る変調器もアタック速度が0なら対象にしません。従来の帯域制限で扱える単純な正弦波を
再処理せず、実際に動く変調器が残る場合に限定します。

判定には発音時に設定されたアタックの速度を使います。小さい音や、後から余韻が終了した
演算器を条件にしません。MA7の低位ビットによって動くAR0も対象外です。
音符の途中で従来経路からFIRへ切り替わることを防ぎ、再発音時に条件を更新します。

元のnative tickを一度だけ進め、そのサンプルを終点に残します。無音の枝・使われない枝の
位相、EG、LFOも元の速度で更新し、既存の混合係数・発音枠・共通72フレーム遅延を保ちます。
音量の正規化は加えません。r87で適用を広げ、r88で単純正弦波を従来経路へ戻しました。
変換キャッシュはr88、正式版は1.6.6のままです。

## 基準波形と境界の検証

`tools/fm-reduced-graphs-test.cpp`で、音程60/72/84/96、二組の周波数倍率、三段階の
変調器TLを検査します。独立したBessel側帯波モデルに接続6の直接音と有限FIR・出力LPの
応答を加え、通常・遅延対照・2/4/8/16/32倍のExact/Hermite、864設定を比較しました。
最大モデルRMS誤差は約7.94e-8、72条件の自動密度は明示した倍率の出力と完全一致しました。

音程96、キャリア5・変調器7・TL0の定常例では以下でした。

| 接続 | 従来の理想帯域とのRMS誤差 | 自動16倍 |
| --- | ---: | ---: |
| 3 | 0.195654 | 0.00000849283 |
| 4 | 0.195654 | 0.00000849283 |
| 6 | 0.0978268 | 0.0000045999 |

180条件でnative終点のビット値・位相・EG・LFO・Hold・発音状態を比較しました。
39の対象外対照には動くアタック、MA7低位ビット、各演算器の非正弦波・フィードバック、
不完全な4演算器設定、残る変調器も停止した単純正弦波を含めます。通常のアタックが終了しても対象にならず、再発音で
条件が更新されることも確認します。

さらに、ゲート1/44/441フレーム、通常NoteOff/AllSoundOff、8倍/16倍の36条件で、
別の接続0/7を参照に開始・終了の波形を比較します。接続6の参照は混合係数の差だけを
別計算し、共通リミッターが動いていないことを確認します。

## アプリ経路と範囲

実ファイル27素材では対象18素材のWAVが独立した明示倍率の出力と一致し、対象外9素材は
変更前のアプリと完全一致しました。従来のアプリ用32素材も完全一致です。
ネイティブAPIの既定経路では既存2,121素材のWAVが完全一致しました。
実WAV/JNIの保存・再生、携帯風の有無、シーク、曲末、書き込み失敗の検査を維持します。
PCM・独立ATRと混在するパート寄与検査は固定倍率48条件、自動密度48条件へ拡張しました。

これは自作の音色とソフトウェア基準による検証で、実曲の聴感や旧端末との一致の測定では
ありません。全演算器が動く接続3/4/6、非正弦波やフィードバックは引き続き対象外です。
極端な変調に対する16倍を超える自動処理も未対応です。Android端末での負荷・消費電力は未測定です。
