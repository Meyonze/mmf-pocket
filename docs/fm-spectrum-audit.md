# FMキャリアのスペクトル測定

`tools/fm-spectrum-audit.cpp` はアプリと同じ `FmOperator` を直接動かし、
サイン・矩形・三角・のこぎり波の持続音を測るホスト用診断です。
音源を変更せず、高音域の折り返し対策に向けた比較基準を残します。

```sh
mkdir -p build/fm-spectrum-audit
c++ -std=c++20 -O2 -Wall -Wextra -Werror \
  -Ithird_party/yamaha-smaf-player/src tools/fm-spectrum-audit.cpp \
  third_party/yamaha-smaf-player/src/ma_fm_core.cpp \
  -o build/fm-spectrum-audit/fm-spectrum-audit
build/fm-spectrum-audit/fm-spectrum-audit --self-test
build/fm-spectrum-audit/fm-spectrum-audit > build/fm-spectrum-audit/baseline.json
build/fm-spectrum-audit/fm-spectrum-audit --bandlimited > build/fm-spectrum-audit/filtered.json
```

追加ライブラリ、楽曲、ROM、ネットワーク接続は不要です。
自己検証は通常のJSON出力時にも実行します。引数エラーは終了コード2、
自己検証・出力エラーは1、成功は0です。

r60以降の `--bandlimited` は、無変調キャリア用の補正を明示的に有効にします。
省略時は従来の発振器を測定し、JSONの `bandlimited_carrier` に選択状態を残します。
アプリ本体はFM合成の接続も検査してから有効にするため、全波形への一括適用ではありません。

同じ基準条件でのr60補正後の残差割合は次のとおりです。

| 波形 | 約366 Hz | 約2,735 Hz | 約8,635 Hz |
| --- | ---: | ---: | ---: |
| 矩形 WS6 | 0.0172% | 0.1326% | 1.0566% |
| のこぎり WS24 | 0.0246% | 0.1489% | 0.9867% |

後述のr59基準値と同じ指標です。基音振幅の検査も別に行い、単に音全体を小さくして
残差を減らす評価を避けています。単独の持続音の測定であり、実曲全体の音質スコアではありません。

## 条件と指標

44,100 Hz、2,048フレームを測定します。4,096フレームのウォームアップ後、
AR15・DR/SR0・SL0・MULTI1・TL0・KSL0の持続音を使います。
AM、ビブラート、フィードバック、外部位相変調は無効です。
modernプロファイルで波形番号0・6・16・24を測ります。
基音をFFTの17・127・401番ビンに合わせるため、この条件では矩形窓の端点による
通常の周波数漏れを避けられます。音高は約366.06・2,734.72・8,634.81 Hzです。

`nonharmonic_fraction` は、DCを除いた全電力のうち、ナイキスト周波数未満の
基音の整数倍ビン以外にある電力の比率です。ナイキストビンは残差に含め、
DCとナイキスト電力も別途記録します。片側スペクトルの通常ビンを2倍、
DC・ナイキストを1倍として、時間領域の平均二乗と整合させています。

折り返した成分が許容する整数倍ビンに重なる場合は、この指標に含まれません。
逆に浮動小数点誤差も残差に含まれます。したがって、全折り返し電力や歪み率を
直接測定する指標ではなく、将来の変更を同じ条件で比較するための観測値です。
無音化して数字だけを下げる変更を避けるため、総AC電力・DCも確認します。

## r59の基準値

2026-10-30のホストGCC測定です。値は全AC電力に対する残差の割合です。

| 波形 | 約366 Hz | 約2,735 Hz | 約8,635 Hz |
| --- | ---: | ---: | ---: |
| サイン WS0 | 0.000001%未満 | 0.000001%未満 | 0.000001%未満 |
| 矩形 WS6 | 0.674% | 5.040% | 18.943% |
| 三角 WS16 | 0.000077% | 0.0311% | 1.447% |
| のこぎり WS24 | 1.002% | 7.143% | 24.009% |

高い矩形・のこぎり波を、今後の折り返し低減の検討対象にする根拠になります。
この割合は聴感上の悪さや改善率ではありません。プレーヤーの最終フィルター、
音量制限、PCM16変換、Android出力経路を含めず、実曲や端末の音質も測っていません。
動的なFM側帯波や複数演算器の対策を、この単独キャリアの結果だけで選ぶことはできません。

この基準を受けた[折り返し低減の試作](fm-antialias-prototype.md)では、
位相変調を含む108条件と処理負荷を比較しています。広範囲への適用は不採用とし、
r60では、接続を検査した無変調の最終出力だけに限定して組み込んでいます。

自己検証は、8点の直接DFTとの一致、既知の基音・第2高調波・非整数倍成分・DC・
ナイキスト成分の電力、無音、実際の発振器と解析的サイン波の一致、既存の
ナイキスト抑制を確認します。メーカー音源の再現度を検証するものではありません。
