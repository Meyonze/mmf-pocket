# r96：VM35とMA7のFM変調の深さを2.5サイクルへ

## 変更内容

Mobile/MA7のモダンプロファイルで鳴るVM35形式のFM音色と、全演算器がMA7形式のFM音色の
位相変調の深さを、4サイクルから2.5サイクルへ変更しました。両形式は同じ値を共有します。
互換形式とMA3/5の扱い（0.42サイクル）は変わりません。変換キャッシュは `r96-pm-depth-2p5-v1` です。

4サイクルは、独立したFMの参照実装から導いた正規化（2^13×2^15/2^26）でした。r92では、
MA7の1曲の外部録音との比較から、MA7もこの値にそろえました（そのときの最適は約3）。

## 根拠：形式の違う2曲

同じ編曲の外部録音（どちらも動画の音声）と、時間を揃えて比べました。

- 曲A：MA7（Format 3）。FM音色はすべてMA7形式。
- 曲B：Mobile（Format 2）。FM音色はすべてVM35形式で、正弦波以外の波形とフィードバックを多く使う。
  ROMのドラム波形は代替音色ですが、250 Hz〜4 kHzでは出力のほぼ0%で、比較はFM音色で決まります。

両方の深さを同じ値にして、2〜4サイクルで描画し直しました。

| 深さ | 曲B：高音の偏り | 曲B：時間変化の誤差／相関 | 曲A：高音の偏り | 曲A：時間変化の誤差／相関 |
| --- | --- | --- | --- | --- |
| 4（旧） | −5.3 dB | 3.79 / 0.604 | −1.6 dB | 3.49 / 0.486 |
| 3.5 | −4.3 dB | 3.70 / 0.602 | −0.9 dB | 3.45 / 0.505 |
| 3 | −2.9 dB | 3.45 / 0.635 | +0.3 dB | 3.43 / 0.523 |
| 2.75 | −2.0 dB | 3.34 / 0.642 | +1.0 dB | 3.43 / 0.531 |
| **2.5（採用）** | −1.3 dB | 3.26 / 0.646 | +1.7 dB | 3.41 / 0.539 |
| 2.25 | −0.4 dB | 3.33 / 0.613 | +2.4 dB | 3.42 / 0.547 |
| 2 | +0.6 dB | 3.35 / 0.587 | +3.2 dB | 3.45 / 0.550 |

「高音の偏り」は、1 kHz以上と1 kHz未満の、録音に対するレベル差の平均です（負はこちらが明るい）。
2.5では、2曲での最大の偏りが1.7 dBと最小で、時間変化の誤差（平均3.33 dB）と相関（平均0.593）も
最良でした。4では、曲Bの中高域（1〜2 kHz）が録音より5〜6 dB強く出ていました。

## 限界

- 根拠は2曲です。どちらの録音も音源（実機か別のソフトか）は分かっていません。
- 曲Bの録音はモノラルで、広がりの比較には使えませんでした。
- 曲Bの録音は曲の終わりのあと繰り返しが続くため、アプリが鳴っている区間だけで比べています。
- 曲Aでは、2.5は録音よりわずかに暗め（+1.7 dB）です。
- 16倍処理の対象（変調器TL24以上）は、4サイクルで検証した範囲のままです。深さが下がったので
  安全側ですが、対象を広げる検証はしていません。
- 聴感での確認は、ここでは行っていません。

## テストの更新

深さは `ma_fm_core.h` の `kModernPmDepth` にまとめ、エンジンとテストの独立した基準が同じ値を
参照するようにしました（基準の計算方法はエンジンから独立したままです）。

深さ4のときの状態を前提にした研究用の検査は、次のように直しました。条件を緩めて通したのではなく、
深さ2.5での実測値と、検査の目的に合わせています。

- `fm-adaptive-density-test`：最も強い高音の例で、16倍の改善が1/1000以上から約1/30〜1/40に
  なったため、条件を1/20未満に。16倍へ切り替わる最初の音程（85から92に移動）を、
  深さから計算して選ぶように。
- `fm-parallel-pair-prototype-test`：TL0のVM35の組は、8倍でも誤差約0.0019と、もう難しい例では
  なくなったため、「32倍が8倍の半分未満で、0.002未満」に。
- `fm-recursive-nested-test`：必要倍率の分類（16/32/64/128/不足）が揃うよう、研究用の6音色の
  1つを差し替え。数式の基準は、必要なときだけ作るように。
- `fm-nested-sine-test`：基準の切り捨て誤差の上限を1e-12から1e-10に（比較の許容差2e-6より
  4桁小さいまま）。
- `render-contribution-audit-test`：ピッチベンドで16倍へ切り替わる境目の音程を、深さと音色から
  計算して選ぶように。
- `vm35-modulation-regression.h`：のこぎり波×矩形波の5倍音の確認を、「基音を上回り、比が互換形式の
  4倍以上」に（深さ2.5で比1.17、互換形式0.20）。

## 残る差の調査（変更なし）

r96の後も、曲Bでは0.8〜2.5 kHzがこちらで約5 dB強く出ます。チャンネルごとに見ると、過剰は
接続3・4（直列のつなぎを含む）の音色に集中し（その帯域の出力の約75%、録音との差−5.5〜−8.4 dB）、
接続5・7の音色は録音と合っていました（+0.3〜+0.7 dB）。そこで、変調器を変調する内側のつなぎ
だけを0.35〜0.7倍に弱める仮説を試しましたが、曲Bの1 kHz帯は−4.8から−5.0 dBと変わらず、
時間変化の指標もほぼ変わりませんでした。仮説は採用していません。過剰の音色は、フィードバックと
正弦波以外の波形も使っていますが、その換算はMA-5の資料に基づくため、根拠なく変えていません。

## 3曲目の参考

別のMA7の1曲（FM音色は少なく、変調が弱い。大半はPCM音色）でも、同じ深さの掃引をしました。
深さを2〜4で変えても、偏り（+2.4 dB）、誤差（3.0 dB）、相関（0.52〜0.53）がほぼ動かず、
この曲は、深さの根拠には使えません（裏付けにも反証にもなりません）。
