# MMF Pocket 1.6.5

MMF内部の曲名・作者を表示し、再生領域をコンパクトに整理しました。
音声の変換処理と、録音波形・発音・曲末の扱いも改善しています。

## 曲情報と再生画面

- MMF内部の曲名・作者情報を表示。
- 情報がない曲はファイル名を表示し、前の曲の作者情報を残しません。
- まふと文字の大きさを保ち、通常表示の再生パネルを18dp、一覧との間隔を4dp縮小。
- 再生状態・設定、シークバーと時刻、操作ボタンを整理。

## 音声と再生処理

- Yamaha ADPCMの整数計算の端数を修正し、高い比率でのサンプル変換の折り返しを低減。
- 変調を受けない最終出力の矩形波・のこぎり波に限定して、FM高調波の折り返しを低減。
- 録音音声が別トラックの同じ番号の波形に置き換わる問題や、同時発音時の置き換え順を修正。
- 不完全な音色定義、無音の音源、末尾の未対応命令、置き換わった録音による曲末の誤りを修正。
- 停止後の意図しない再開と、再生準備・シーク中の音量変更の取りこぼしを修正。
- 音声を保つ範囲で合成処理を軽量化。

変換キャッシュはr63です。更新後は古い変換音声を再利用せず、新しい処理で変換します。
端末固有ROM音色や未対応エフェクトを新たに再現するものではありません。

## インストール

- Android 10以降。
- 同じ署名の通常公開版は上書き更新できます。
- APKのハッシュは添付のSHA256SUMS.txtで確認できます。
- 署名証明書 SHA-256：`1C79EF3491BD915618F989E053C29648AF1AF0910D9E7150919D0D64D896C59E`

配布するのは署名済みの汎用APKとチェックサムです。楽曲データや署名秘密鍵は含みません。
