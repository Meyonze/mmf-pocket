# 高音域の三角波キャリア（r65）

modernプロファイルのWS16（三角波）のうち、変調もフィードバックもない最終出力だけを
補正します。適用する演算器の判定は、r60の矩形波・のこぎり波と同じ接続検査を使います。
生きた変調器、フィードバック、従来プロファイル、不完全な演算器構成は対象外です。

## 補正する範囲

三角波の倍音は奇数次だけです。演算器の周波数が出力レートの1/6を超えると、
第3倍音以降はすべてナイキスト周波数を超え、出力に含められるのは基音だけになります。
この範囲で元の三角波から基音 `8/π² × sin(2πphase)` へ滑らかに移行します。
移行はレートの1/6から1/5の間で行い、両端で傾きが0になる補間を使います。
44.1kHzなら約7,350Hzから8,820Hzです。音符番号だけでなくMULTI・detune・vibratoを
含めた実際の演算器の位相増分で決めます。従来のナイキスト抑制と位相進行は維持します。

1/6以下の出力は、元のfloat丸めも含めて保持します。基音を消したり全体を減音する
方法ではありません。既存の4096分割の共有正弦テーブルを再利用し、音ごとのメモリ割り当てや
フィルター状態を追加しません。周期正規化が丸めでちょうど1になる境界も処理します。
変換キャッシュはr65へ更新します。

全域にPolyBLAMPと振幅補正を適用する試作は不採用です。独立した有限フーリエ級数との
比較で、2,048フレームの17番ビンでは二乗誤差が従来の約1.58倍、127番ビンでは約1.10倍に
増えました。高音域で改善しても、低・中音域まで同じ補正を広げる根拠にはしません。

## 音声の検証

- 294条件の周波数・初期位相を独立した解析的な基音と比較し、誤差の増加はありません。
  完全に移行した範囲の最大RMS誤差は約8.92e-8でした。
- 8kHz・44.1kHzの持続音で基音振幅、DC、低・中音域の一致を検査します。
  全8接続方式の適用範囲、変調・フィードバックの保持、奇数アタック、再発音、
  音程変更、ビブラート、補正の切替境界も検査します。
- 既存222素材はWAV全体がバイト単位で一致しました。前回のr64修正も保持しています。
- 新しい37素材は対象18素材だけが変化し、他の19素材は完全一致しました。
  全素材で形式・フレーム数は維持しました。合計259素材中241素材が一致します。

新素材は `tools/generate-triangle-probes.py <新規ディレクトリ>` で生成できます。
全8接続方式、低い音、移行域、高い音、生きた変調器、フィードバック、
ビブラート、補正範囲をまたぐ音程変更を含む、自作の単音素材です。

音声回帰、FM帯域制限、FM位相、高比率のPCM変換、入力保護の5スイートを
ASan/UBSan付きで確認しました。境界修正後にはFM帯域制限・位相を再検証し、
周期端点の回帰も追加しています。クラウドではリーク検査を無効にした
`ASAN_OPTIONS=detect_leaks=0`で実行しています。Android 3 ABIのDebug・Releaseと
lintも通過し、lintはエラー0件・既存警告4件です。

## スペクトルの測定

44.1kHz・2,048フレーム、4,096フレームのウォームアップ後の単独の持続音です。
測定器は `tools/fm-spectrum-audit.cpp --bandlimited` を使います。
DCを除く全電力のうち、ナイキスト未満の基音の整数倍ビン以外にある割合を示します。

| 周波数 | 補正前 | 補正後 |
| --- | ---: | ---: |
| 約366Hz | 0.0000773% | 0.0000773% |
| 約2,735Hz | 0.03114% | 0.03114% |
| 約8,635Hz | 1.44660% | 0.002792% |

最後の条件の残差電力は約27.21dB減りました。基音振幅は別に検査しています。
折り返しが整数倍ビンに重なる成分は数えないため、全折り返し電力や音質スコアではありません。
実曲・最終PCM16・Galamelo・旧端末との音色一致を評価した数値でもありません。

## 負荷と残る項目

32音のFmVoiceを使い、同じCPU・プロセスで新旧を短い区間ごとに交互測定しました。
48条件・5組の探索的なホスト測定では、対象の高い三角波の中央値比は約1.01〜1.02でした。
一方、対照条件の中央値比も約0.81〜1.19とばらつき、個別の組ではさらに大きな変動が
あります。速度差の確定値や、すべての条件で負荷が増えないという根拠にはしません。
Androidの処理時間・消費電力は未測定です。追加処理は独立した関数に分けています。

低・中音域の三角波、他の未対策波形、動的なFM側帯波・フィードバックへの対策は残ります。
今回の結果だけで適用範囲を広げません。
