# r91：MA7の直列変調を16倍で処理

MA7の正弦波・実効フィードバックなしの接続6（直接音0と、1→2→3の直列変調）を、
通常再生の16倍ソースへ追加しました。全4演算器がMA7形式で、変調器1/2とキャリア3の
設定アタックが停止していない場合が対象です。固定周波数と非ゼロのDetune指定は対象外です。
変換キャッシュはr91、正式版は1.6.6のままです。

## 変調の範囲

現在のソフトウェアでは、MA7の変調深度の最大値は0.42cycleです。TL0でも、r90で確認した
VM35の4cycle・TL24（約0.504cycle）を下回ります。このため対象MA7はTL0〜63を扱います。
互換形式や、MA7とVM35が混在する演算器設定へは広げません。
単一の変調器・キャリア用の密度推定は流用せず、対象は全音程で16倍を選びます。
既存の停止アタックによる簡約接続6は、従来の8/16倍選択を維持します。

元の1フレームにつきnative tickは一回です。EG・LFO・発音枠の時計、元のサンプル終点、
接続6の0.5倍の混合、既存のMA7音量・パン、共通72フレームの遅延を保ちます。
演算器がnative Nyquistを超えた場合のミュートも維持しています。

## 独立した基準と検証

既存の二重Bessel展開を、MA7の0.42cycleと独立した周波数倍率表へ拡張しました。
分数倍率0.5/1.414/1.498/0.891を含め、周波数を1/1000単位でまとめます。
係数和と入れ子の正弦波の直接計算を照合し、次数の打ち切り・省略誤差も評価します。
基準にはMA7のFormat3譜面、展開音色定義、左端のパン利得1も含めます。

- MA7の75素材とVM35の75素材、合計1,500の倍率・数式方式で、有限FIR・LPの独立基準と比較。
  最大RMS差は約1.54e-8、native公開プレイヤーとの最大差は約2.10e-8でした。
- 分数倍率を含むMA7二構成を追加し、短音・強制停止・通常NoteOff・音程変更を計108条件で比較。
  独立した密なFIR畳み込みとの最大RMS差は約5.74e-9、ピーク差は約2.42e-8でした。
- 320条件で位相・EG・LFO・Hold・微小音・再発音を照合。MA7の途中サンプルも独立した
  ホスト試作とビット比較し、元のnative終点と発音状態を維持しています。
- 実ファイル82素材で、対象75素材のアプリWAVが明示16倍と完全一致し、対象外7素材はr90と一致。
- 既存2,262入力を含む計2,344入力で、音声が変わったのは新しい対象75素材だけでした。
  発音状態とカウンターは全件一致。従来の二件は時間上限までの比較で、追加82素材は曲末まで比較しています。
- 実WAV/JNIの36構成と、固定倍率64・自動方針64の混在パート検査へ拡張しました。

GCC Release、ASan/UBSan、NDK ClangのLinuxホスト向け実行と、Android全ABIの
Lint/Debug/Releaseを確認しています。ホスト実行はAndroid実機での実行ではありません。

## 残る制約

これは既存のソフトウェア音源の折り返しを抑える変更です。実機チップの変調深度や
ROM音色への一致を測ったものではありません。有限FIRの遷移帯域には誤差が残り、
16倍がすべての入力で8倍より理想帯域に近くなる保証もありません。
新たな音色では16倍の計算量が加わり、端末上の速度・電力は未測定です。

強いVM35変調、互換形式、全演算器が動く接続3/4、フィードバック、固定周波数・Detuneの
検証は残っています。native Nyquistを超える演算器から帯域内に戻る成分の回復も、
曲末と発音枠を含めた別の対応が必要です。
