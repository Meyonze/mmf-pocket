# 代替音色の音量・余韻の測定

PCM音色の設定が代替時に失われる影響は、
[共通処理の調査と30素材での再現](fallback-envelope-audit.md)にまとめています。

`tools/profile-fallback-balance.py`で、同じ条件の自作単音を鳴らし、代替音色の
立ち上がり・持続部・余韻を測定できます。元の曲やメーカーの音色・ROMは含みません。
音量校正のための現状把握であり、端末との一致や聴感上の優劣を示す測定ではありません。

## 実行

```sh
cmake -S third_party/yamaha-smaf-player -B build/balance-render -DCMAKE_BUILD_TYPE=Release
cmake --build build/balance-render --target smaf-render -j2
python3 tools/profile-fallback-balance.py --renderer build/balance-render/smaf-render build/balance-results
```

出力先は新規ディレクトリに限定し、既存のパスは上書きしません。
`--quick`は代表18素材だけを測る動作確認用です。

- `manifest.json`：素材の条件、入力・レンダラーのSHA-256、完了状態。
- `measurements.csv`：PCM16単位のピーク、RMS、DCを除いたAC RMS、左右別DC、WAVのSHA-256。
- `*.mmf`・`*.wav`・`*.log`：再確認用の素材、変換結果、変換ログ。

すべて終わるとmanifestの`status`が`complete`になります。失敗・中断時は`generated`のままなので、
途中までのCSVと完了した測定を区別できます。入力の書き換えや、途中でレンダラーが変わった場合も
完了扱いにしません。

## 条件と測定範囲

Mobile/MA-7それぞれ140素材、計280素材です。各形式で次を含みます。

| 対象 | 条件数 |
| --- | ---: |
| GM代替16系統の代表プログラムを音符48・60・72で測定 | 48 |
| ROM代替：打楽器22波形は音符60、ピアノ・弦の7波形は3音程 | 43 |
| 定義のないドラム：キー35〜81 | 47 |
| 自作の埋め込みFM・RAM PCM対照 | 2 |

Volume・Expressionは127、Panは64、Velocityは100。250msから発音し、ゲートは500ms、
EOSは1000msです。ROM指定には独自のFM近似音色を使います。ROMのFs指定は16kHzに固定し、
当時のROMの実際のチューニングを再現する値とは扱いません。
PCM対照は自作波形を使い、代替音色の校正基準にはしません。

44.1kHz・ステレオPCM16を、最大4秒まで測定します。

| 区間 | ファイル先頭からの時間 |
| --- | --- |
| whole | 250〜4000ms |
| attack | 250〜350ms |
| body | 350〜750ms |
| release | 750〜2750ms |

左右を足し合わせず、2チャンネルの電力を平均します。AC RMSは左右それぞれの平均値を
除いて計算するため、逆相やDCを音量と混同しません。自然終了後はゼロで補い、区間長を揃えます。
`render_bound_hit`はWAVが4秒の測定上限まであることを示し、自然終了を保証するフラグではありません。
RMSはLUFSや聴感上のラウドネスではなく、単音の波形レベルです。音色間の差だけでは
音量過大と判定できず、実曲の音符数・音程・パン・強弱・埋め込み音色との混在も別途影響します。

## r68の初回結果

エンジン`e9e9f58`相当のホストビルドで280素材を測定しました。全素材が有音で、
4秒の上限に達した素材はありませんでした。独立した音色調査ツールでも、全280素材の
代替経路・波形番号・250msの発音時刻・論理音符数1を確認しました。

MA-7・音符60の代表GM16系統では、body区間のAC RMSの最大差は約7.94dBでした。
次の数値はPCM16単位です。プログラム番号は0始まりです。

| 代替音色 | プログラム | attack AC RMS | body AC RMS | release AC RMS |
| --- | ---: | ---: | ---: | ---: |
| ピアノ系 | 0 | 1475.71 | 559.36 | 14.36 |
| オルガン系 | 16 | 671.00 | 667.73 | 22.24 |
| ベース系 | 32 | 2362.54 | 1395.50 | 121.17 |
| 弦系 | 40 | 1307.76 | 1097.35 | 68.08 |

弦系のbodyはピアノ系より約5.85dB大きく、余韻の区間にも差があります。
これは代替音色の減衰・持続がミックスに影響し得ることを調べる出発点です。
ユーザーが気になった曲の原因や、正しい楽器間の比率を確定するものではありません。
今回はアプリの音声処理や音色パラメーターを変更せず、キャッシュはr68を保持しています。

## 検査

`python3 tools/profile-fallback-balance-test.py`で、逆相・DC・固定区間のゼロ補完、
PCM16端点、壊れたWAV、決定的な自作素材、既存パスの保護、変換失敗、入力改変、
無音判定との整合性を確認します。偽レンダラーを使う検査は合成品質を検証しません。
`--audit-binary <tone-usage-audit>`を渡すと、実際のエンジンで全280素材の経路と時刻も確認します。
両方をCIに追加しています。
ローカルではネイティブの経路確認を含む11検査が通過し、代表18素材を再測定した入力・
WAVのSHA-256とすべての測定値も一致しました。
