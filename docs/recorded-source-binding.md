# 録音音声の参照先が別トラックに変わる問題（r63）

Mobile形式の録音音声（Mwa）は、発音を記録したMTRトラック内の波形番号を参照します。
しかし、後からMA-7トラックを読むと共有チャンネルの参照元が上書きされ、Mobileの発音が
そのMA-7トラックの同じ番号の波形を使っていました。波形がなければ無音になります。
後続トラックには終了指示だけを置いても再現し、読み込む順番によって結果が変わります。

## 修正

既にMA-7で行っていたように、通常・圧縮Mobileの発音にも元のトラック番号を保持します。
録音音声の再生と音色診断は、その番号を優先して参照します。番号を持たない従来形式や
内部の検証用発音は、以前のチャンネルによる参照方法を保ちます。

波形の復号・再構成、2音の専用枠、発音順、音程、ゲート、音量・定位の既存処理は同じです。
混在時のチャンネル設定そのものの仕様を新しく決める変更ではありません。
以前の誤った録音がキャッシュに残らないよう、変換キャッシュをr63へ更新します。

## 検証

専用ネイティブ試験では96通りの混在を確認します。通常・圧縮形式、Mobileトラック0/1、
波形番号1/14/32、明示・記憶したベロシティ、相手の波形の有無、トラック順を組み合わせ、
シーク・再初期化・読み取り単位も比較します。元の波形がない場合、別トラックの波形を
借りずに無音と診断を維持すること、44.1kHzへの変換も確認します。

対照では共有チャンネルの設定を同じにし、元の波形を両方のトラックに置きます。
対象素材では相手側だけを別の波形や波形なしに変え、元の録音が変わらないかを比べます。
トラックを加えると従来の定位カーブも変わるため、混在素材と単独素材をそのまま
完全一致の対照にすると、今回の問題以外の差まで拾ってしまいます。

新しい32個の自作MMFは、コンテナ長とCRCを独立検査しています。既存158個と合わせた
190個のWAV比較では対象12個だけが変わり、残り178個は完全一致しました。
20組の参照素材との比較も完全一致です。新しい素材は2秒の上限より前に最後まで変換し、
既存素材はそれぞれ以前と同じ12秒・35秒の上限を使っています。

32素材のスコア診断は変更前と完全一致し、音色診断では全素材が正しい参照元と
波形の有無を報告します。以前の参照先が違っていた16素材の詳細レポートは修正されます。
同じ波形を両方に入れた対照4個も含むため、音声が変わる12個とは件数が異なります。

ASan/UBSan付きの関連6スイート、診断CLIの13チェックと自己検証、Android全3 ABIの
lint・Debug・Releaseが通過しました。lintはエラー0件・既存警告4件で、APK署名も検証済みです。
この環境ではリーク検査を無効にしています。端末での新しい聴感・速度測定は未実施です。
これはソフトウェア内の波形参照の修正です。メーカーROM、端末の音色調整、別アプリとの
比較録音に基づく変更ではありません。素材に個人の楽曲やメーカーの波形は含みません。
