# 接続6の直列3演算器：ホスト試作

r90では[検証した弱いVM35の範囲](fm-weak-nested-r90.md)を通常再生へ適用しています。
この試作は、範囲外の形式・変調量も調べるためのホスト検証に引き続き使います。

`tools/fm-nested-sine-probe.h`は、全演算器が動く接続6の追加サンプル生成を試す
ホスト専用の実装です。接続は`op0 + (op1 → op2 → op3)`で、元の0.5倍の混合を保ちます。
正弦波4演算器・実効フィードバックなしだけを扱い、2/4/8/16/32倍のExact/Hermiteを試せます。

元の`tick()`を一度だけ進め、位相の始点と更新後のEG・LFOから途中の波形を作ります。
元のサンプルを終点に残し、nativeの発音枠・終了・recentLevelの判断を保ちます。
バッファ・形状・倍率の拒否時には、出力も時刻も変えません。

## 独立した数式基準

直列部分を以下のように表します。位相と変調指数はラジアンです。

```text
sin(Ct + β2 sin(Mt + β1 sin(It)))
  = Σ_n Σ_k J_n(β2) J_k(n β1) sin((C + n M + k I)t)
```

`tools/fm-nested-sine-test.cpp`は、VM35の既存4cycleの変調深度、変調器TL24/24、
直接音TL18の独立モデルから始め、r90では変調器TL24/36/63へ広げています。演算器の内部設定値は数式へ読み戻しません。
符号・周波数の検査は、Bessel和を直接の入れ子の正弦波と128点ずつ比較します。

外側は次数±32、内側は±256までを取り、既存の絶対尾部上限と
`Σ |J_n(β)| ≤ exp(β)`で打ち切り誤差を評価します。整数倍の周波数をまとめた後で
省略する係数も、その絶対値和が1e-12未満であることを要求します。
直接音・0.5の混合・有限FIRの複素応答・既存の出力LPを別計算します。

初期の音程72/84/96、二組の周波数倍率の計4素材に加え、r90では計75素材へ広げました。
以下は拡張後の検査です。nativeの演算器ミュートは参照にも含めます。

- 元の公開プレイヤーと数式基準：最大RMS誤差約2.10e-8。
- 試作から実際に追加サンプルを作り、FIRとLPを通した750設定：最大RMS誤差約1.54e-8。
- ExactとHermiteの差：RMS1e-7未満。
- 自動8/16の方針を指定した対象VM35の通常プレイヤー：明示した固定16倍と完全一致。

高い変調の一例（音程96、内側倍率7・中間3・キャリア5）での、理想帯域とのRMS誤差です。

| 試作倍率 | RMS誤差 |
| --- | ---: |
| 8 | 約0.000343431 |
| 16 | 約0.00000732092 |
| 32 | 約0.00000520121 |

240条件で低・通常サンプルレート、三つの形式、EVB/AM、低位アタック、音程変更、微小音、
Hold、再発音を検査しました。元の終点・再計算した終点のビット値、位相・EG・LFO・
フィードバック履歴が一致しました。発音終了後を含む4条件と、不正な形状・倍率を拒否する
15条件も検査します。Release、ASan/UBSan、NDK ClangのLinuxホスト向け実行で通過しました。
これはAndroid実機での実行ではありません。

## 通常再生への適用前に残ること

試作ヘッダー自体はアプリへ組み込まず、r90の限定したVM35だけを公開source側で扱います。
強い変調や範囲外の形式を通常再生へ広げる前に、さらに検証します。

側帯波モデルは定常音です。別途、限定したRR15・短音・音程変更の36条件を独立した波形と
密なFIR畳み込みで確認しました。さらに強い変調、別のEG・AM条件、範囲外の形式と負荷の検証が必要です。
既存の2演算器向け密度上限をそのまま流用できません。有限FIRの遷移帯域の誤差もあり、
倍率を増やせば全条件で単調に良くなる保証はありません。音量正規化や旧端末への一致を
示すものでもありません。r90のアプリ適用・キャッシュ変更は上記の専用ページを参照してください。正式版は1.6.6のままです。


## r91のMA7拡張

[MA7接続6](fm-ma7-nested-r91.md)も、固定周波数・Detuneなしの範囲を通常再生へ追加しました。
現在の検査はVM35/MA7の150素材・1,500設定です。MA7の分数倍率とFormat3譜面を含め、
パンの基準も別に計算します。時計の照合は320条件、独立した短音・音程変更・余韻は
108条件へ拡張しています。試作は引き続き未対応範囲の検証にも使います。
