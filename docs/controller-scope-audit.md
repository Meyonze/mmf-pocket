# 音量コントローラーの適用対象の確認

2026-11-06の調査では、録音PCMの音量をFM/鍵盤PCMと同じルールに変える根拠を
先に確認しました。[Yamaha SMAF3.05](https://img.atwiki.jp/mmfuta/attach/19/78/SMAF3.05.pdf)の
印刷ページ43「Stream PCM」は、音符でMwa波形を開始できる一方で、Control Change・
Program Change・Note Numberの割り当ては「実装系に依存する」としています。

このため、一般的なMIDIのCC7/CC11だけから、現在の録音Audioにも同じゲイン式を
適用すべきとは判断できません。反対に、全機種で無視すべきことを証明する記述でも
ありません。MA3/5・MA7の機種別資料や比較音源が得られるまでは、この範囲を推測で
変更しません。独立したATRは自身の音量イベントで処理する既存の方針を維持します。

同仕様の印刷ページ36〜37の二乗ゲイン式は、HandyPhoneイベントの推奨式です。
これをMobile/MA7すべてに無条件でコピーしたり、既存プロファイルを一括変更したりする
根拠とは扱いません。形式・初期値・録音と楽器の別を確認してから適用します。

今後の調査では、時刻付き診断で発音枠の置換とリミッターの作動・低下量を先に確認し、
指定音色と実際に選ばれた波形・代替音色は音色依存レポートで確認します。実曲の原因を
特定しないまま、楽器別の音量やコントローラー曲線を揃える変更は行いません。

これは適用範囲を確認した記録です。アプリの音量処理、キャッシュ、公開バージョンを
変更するものではありません。仕様書のPDFやメーカー音源データはリポジトリへ含めません。
