# ROM代替打楽器の高域を聞き比べる実験

試聴ではA/Bの差が明確ではないとの報告でした。この高域処理は通常再生へ採用せず、
実験の記録として保持します。r92の振幅重ね掛けも通常再生から外しています。

r92は元のTL・エンベロープを反映する修正で、独自FM代替音色の波形を作り直すものではありません。
代替音色22アドレスを同じ周波数で鳴らすと16種類の出力になり、4/5、7/8、11/21、13/18、
14/16/17はそれぞれ同じレシピです。元のROM打楽器を正確に再現した音色ではありません。

PCMのFsは現在、代替FMのピッチに反映しますが、代替FMが持つ高域は元のサンプル帯域に
制限しません。調査対象のスネア代替では、通常の出力LPを通した単音でもFs/2より上の電力が
約11～13%ありました。これはソフトウェアの測定で、実機の余分なノイズを測った値ではありません。
サンプル再構成のイメージ成分や振幅変調もあるため、Fs/2より上の成分が常にゼロであるべきだと
断定するものでもありません。

`tools/percussion-bandwidth-preview.cpp`は、音色の違和感に高域が寄与するかを聞き比べる
ホスト用の実験です。Androidの再生処理・キャッシュ・テストAPKは変更しません。

```sh
c++ -std=c++20 -O2 -Ithird_party/yamaha-smaf-player/src tools/percussion-bandwidth-preview.cpp build/native-render/libsmaf.a -o build/percussion-bandwidth-preview
build/percussion-bandwidth-preview --self-test
build/percussion-bandwidth-preview input.mmf new-preview-folder 20
```

- `A-current-r92.wav`：r92の通常アプリ品質の出力。独立した無計測レンダラーとの一致を検査。
- `B-source-bandwidth-trial.wav`：既知のROM打楽器のパートにだけ、Fs/2を遮断周波数とする
  4次Butterworthローパスを追加し、全パートの共通リミッターを再計算。
- `reference-check.json`：時計・割り当て・元の音声出力の一致と、検査時間の上限を記録。

Bはパート寄与を元の出力LP後で処理する試作です。製品の音源再構成の代わりではなく、
元の波形、ループ、スペクトルを復元するものでもありません。パート内で波形の再生周波数・音源種別が
混在する入力は停止します。実装へ進む場合はパート単位の後処理をそのまま移さず、音声単位の
再構成、振幅制御との順序、音程変更、余韻と遅延を扱う必要があります。

出力先は新規ディレクトリに限定し、最大60秒・44.1kHz・ステレオPCM16で出力します。
音量の正規化や音符の削除は加えていません。音楽データや生成WAVはGitへ含めません。
自己検査は独立したButterworth振幅式18条件、帯域バイパス、状態保持、混在入力の拒否を確認します。
診断の既存512音源・64混在・64適応品質条件も変更前と一致します。
