# 再生領域の曲情報

再生中のMMFに曲情報があれば、ファイル名の代わりに内部の曲名を表示します。
アーティスト名と、作曲・作詞・編曲の記録があれば、その下の `by 作者` にまとめます。
空の項目は表示せず、曲名がないファイルは従来どおりファイル名を表示します。
曲が変わると作者情報も更新し、次の曲に情報がなければ前の表示を消します。

太字は曲名だけにし、2行まで表示します。直下には通常の文字で `by 作者A / 作者B` と
表示します。アーティスト・作曲・作詞・編曲の順に、記録のある名前をスラッシュで区切り、
同じ名前は一度だけ表示します。作者情報がない曲ではby行を隠します。
長いby行は2行まで折り返し、それ以上は末尾を省略します。
曲情報の親領域は可変の高さにし、76dpの最小高さを撤廃しました。
マスコットは元の84×92dpに戻し、その横に曲名・作者・再生状態と設定を収めています。
上下の余白を各3dp、シークバーと時刻の行を24dp、操作行を48dpに詰めています。
再生ボタンの内部余白も調整し、アイコン自体の大きさは維持します。
通常の文字サイズでは、前版よりパネルを18dp低くし、一覧との間隔も4dp減らしています。
時刻の行は文字が大きい設定では必要に応じて広がります。
名前の項目別の行や、そのための空き領域は設けません。
再生状態・形式・携帯風の切替は曲情報の下に置き、時刻をシークバーの横にまとめています。
下段は再生操作とリピート・ランダムの操作に分け、時刻欄との横幅の競合をなくしました。
再生領域は表示する文字量に合わせて高さが変わります。
WAVの内部タグ読み取りは今回の対象外です。

## 曲名に作者が書き込まれている場合

作者の別項目がなく、ST自体が `いつか終わる夢 by 全てを捨てし者 / game-melody.com`
になっているファイルでは、以前は全体を太字の曲名として表示していました。
表示用の処理でこの形を分離し、曲名を上の太字欄、`by`以降を下の通常文字の欄へ渡します。
元のSTやファイル内容、Media3で保持する元データは変更しません。

単語として独立したbyのうち、作者項目と一致する表記、日本語の作者、
スラッシュ区切りのクレジット、サイト名を伴うものを扱います。
`Stand by Me`のような通常の英語タイトルを単純な単語検索だけで分割しません。
複数のbyがあれば末尾側のクレジットを使い、半角・全角の空白にも対応します。
これは表示のための判別で、作者項目のない曖昧な英語表記すべてを確定できる処理ではありません。

## 読み取り

- CNTIの5バイトのヘッダーに続く `ST:値,AN:値,...` 形式。
  エスケープされたカンマ・バックスラッシュを扱います。
- OPDA内のDchに入った2文字のタグ・BE16長・値の形式。
  Dchごとのコード種別を使い、CNTIの種別を流用しません。
- ST＝曲名、AN（なければAR）＝アーティスト、SW＝作曲、WW＝作詞、AW＝編曲。
  空でないOPDA項目を優先し、不足分をCNTIで補います。
- コード0のShift_JISをWindows互換の文字集合で復号します。
  未対応のコード種別はASCIIだけを採用し、非ASCIIの文字コードを推測しません。

メタデータはJava側で、読み込み済みMMFバイト列から再生準備のワーカー上で取得します。
変換キャッシュがある場合も同じ処理を通ります。Media3のdisplayTitle・artist・composer・
writerと編曲用extrasで画面へ伝え、titleにはファイル名を保持します。
ファイル種別の判定や書き出し名が、内部タイトルの拡張子らしい文字列に影響されません。
準備中に別の曲へ移った場合は既存の世代番号チェックで古い結果を破棄します。

宣言された親チャンクと実データの両方で境界を検査し、音符や波形データ内の文字列は
検索しません。チャンク数・フィールド数・文字列量を制限し、表示文字列は最大256文字です。
壊れた曲情報は読み飛ばし、音声エンジンや変換キャッシュの版はr63を維持します。

## 検証

独立した日本語バイト列（バックスラッシュと同じバイトを含む「ソ」など）、
エスケープ、CNTI/OPDAの優先順、Dch独自のコード種別、空欄・未知のタグ、
宣言長の境界・切り詰め・過大フィールドをホストJavaで検証します。
38項目の検査と3000個の不正入力が通過しています。
画像から転記したSTのみのCNTI・OPDAを含む23ケースで、曲名とby行の分離、重複排除、
全角空白、通常の英語タイトルの保持も確認しています。
架空の検証用クレジットを入れたCNTI・OPDA・情報なしの3個のMMFでも日本語情報を確認し、
3個とも元の素材とWAVが完全一致しています。
Androidのlint・Debug・Releaseも通過し、lintはエラー0件・既存警告4件です。
APK内の3 ABIのネイティブ音声ライブラリもr63版とバイト単位で一致しています。
新しい表示についての端末上の見た目の確認は未実施です。
