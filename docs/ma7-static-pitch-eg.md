# r94：MA7 WT音色の一定のPitch-EGを音程のずらしとして扱う

## 変更内容

MA7のWT+AL+Pitch-EG音色（展開形式の43バイト）は、9バイトのPitch-EGが付きます。
これまでは、9バイトがすべて0の場合だけを受け付け、それ以外は音色ごと捨てていました。
捨てられた音色を使う発音は、汎用のFM近似音色で鳴っていました。

今回、観測した1つの形だけを、一定の音程のずらしとして受け付けます。

- 条件：4バイト目（符号付きのレベル）が0以外、9バイト目が1、ほかの7バイトが0。
- ずらし幅：レベル1あたり10セント（例：0xFD＝−3なら−30セント）。
- それ以外の0でない形（時間で音程が動く可能性があるもの）は、これまでどおり受け付けません。
- 診断では、この音色を「部分対応（Partial）」として記録します（コード0x140、値はセント）。
- 変換キャッシュは `r94-ma7-static-peg-v1` です。

## 根拠と測定

実在するMA7のMMF1曲では、ユーザー波形0番を鳴らす2つの音色定義（バンク124の1・2番、
プログラム48）が、`00 00 00 FD 00 00 00 00 01` のPitch-EGを持っていました。
この2音色は、旋律のパート（150音）と伴奏（42音）、計192回の発音で使われています。

同じ編曲の外部録音と比べました（オンセットで時間を揃え、1セント刻みの対数周波数で、
旋律が主に鳴る時間帯のスペクトルを、周波数方向にずらしながら重ねる方法）。

| こちらの音 | 録音とのずれ |
| --- | --- |
| 汎用FM近似（楽譜どおりの音程） | +0.5セント |
| ユーザー波形0番、Pitch-EGを無視 | −29.6セント |
| ユーザー波形0番、今回の解釈（−30セント） | +0.2セント |

録音は楽譜どおりの音程で、波形をそのまま鳴らすと約30セント高くなります。レベル−3を
−30セントとすると一致します（1単位12.5セントの−37.5セントでは合いません）。
音程は、音全体を通して一定のずれとして観測されました。

なお、音色（帯域ごとの音量）の録音との近さは、ユーザー波形と汎用FM近似で同程度でした
（帯域ごとの差の平均が、約1.5 dBと約1.7 dB）。音色の面で、どちらが録音に近いとは言えません。
ユーザー波形は、作者がMMFに入れた音そのものです。

## 限界

- 根拠は1曲・1つの形だけです。1単位10セントも、1つのレベル値（−3）からの推定です。
- 9バイト目が「有効」を表すのか、ほかのバイトが時間変化の設定なのかは、分かっていません。
- この音色はALフィルター付きですが、ALフィルターは引き続き適用していません。
- 聴感での確認は、ここでは行っていません。

## テスト

`audio-regression` で、次を確認します。

- 観測した形が、−30セントとして読まれる。レベル2なら+20セント。
- すべて0の拡張は、ずらし0のまま（変更前と同じ再生）。
- ほかの7バイトのどれかが0でない形、9バイト目が0の形は、受け付けない。
- 末尾だけが1の形は、従来どおり受け付けない。
- ずらしのある再生は、変更前と異なり、ブロック幅に依存せず、有限。
