# 無音ループを持つPCM音色の補間（r64）

MA-7の符号付き8ビットPCM音色のうち、末尾のループがすべて0のものでも、
modernプロファイルの高品質補間を使います。従来は無音ループを早く終了するために
線形補間へ戻しており、音程変更時の再構成と折り返し低減が他のPCM音色と異なっていました。

ループが無音でも、補間フィルターには直前の音の履歴が残ります。
最大128タップのフィルターが参照する過去63ソースサンプルを通過してから終了します。
短いループの繰り返しも、累積した元波形上の位置で判定します。
その後に音程が変わってフィルターが広がっても、参照されるサンプルはすべて0です。
波形全体が無音でループ開始位置が0なら、履歴を待つ必要はありません。

音量のしきい値では終了しません。0以外のループ、既存の非ループ終端、従来プロファイル、
FM音源、録音Audio/ATRの補間規則は保持します。対象音色には従来の線形補間より計算量の多い
フィルターが使われます。端末上の処理時間は未測定です。変換キャッシュはr64へ更新します。

## 確認した範囲

- 既存190素材は、同じ変換上限でWAV全体がバイト単位で一致しました。
- 新しい32素材では対象15素材だけが変化。その他17素材は一致しました。
- 新素材の符号付き・符号なし16組は、修正後に共通区間のPCMが完全一致しました。
  先に終了した符号付き側の後に、対照側に残るPCMもすべて0です。
- 単体テスト27,909サンプルは、ループを使わずに展開した元波形の結果と一致しました。
  この中には、無音ループ開始後も値が0ではない補間結果1,509サンプルが含まれます。
  比較は同じ補間カーネルを使った履歴検査であり、独立したフィルター精度検査は
  既存の高比率変換テストが担当します。
- 曲全体の回帰テストは7音高で符号なし対照と一致し、1フレームと257フレームの
  読み出し結果も一致しました。既存のシーク・再初期化検査も通過しました。

`tools/generate-silent-loop-probes.py <新規ディレクトリ>`で、自作波形だけを使った
比較素材32個と入力ハッシュ付きmanifestを再生成できます。音程、短いループ、
0以外の値が残るループ、音程変更を含みます。既存190素材と合わせて222素材中207素材が一致し、
15素材だけが意図した変更です。

ASan/UBSan付きの音声回帰、高比率変換、録音Audio、ATR、PCM16出力ブリッジ、
入力保護の6スイートが通過しました。このクラウドではリーク検査を無効にした
`ASAN_OPTIONS=detect_leaks=0`で実行しています。Android 3 ABIのDebug・Releaseビルドと
lintも通過し、lintはエラー0件・既存警告4件です。

## 合成信号の測定

8kHzの元波形を44.1kHzへ変換し、音符番号96・108で再生しました。
音の開始から10〜20msの、境界を含まない同じ区間を測っています。
測定値は最終PCM16 WAVの左右を合わせたRMS電力です。

| 音符番号 | 0.45周期/ソースサンプルの折り返し電力の低減 | 0.01周期/ソースサンプルの振幅比（修正後/前） |
| --- | ---: | ---: |
| 96 | 51.46dB | 1.000332 |
| 108 | 54.31dB | 1.000346 |

高い周波数の合成信号を出力ナイキスト周波数より上へ移した場合の折り返し低減です。
低い周波数の別の信号では振幅を保っています。実曲全体の改善率や聴感スコア、
他の再生アプリ・旧端末との音色一致を表す測定ではありません。
