# MMF Pocket 1.6.0

プレーヤーに3Dキャラクター「まふ」が加わりました。曲の速さに合わせて浮遊、ダンス、ランニングが切り替わり、側転、バク転、フィギュア風の回転などを見せます。

## 主な変更

- 白く柔らかな質感と太い輪郭を持つ、厚みのある3Dモデルの「まふ」を追加
- MMF内のチャンネル別ノート密度から、曲に合う動きの速さを選択
- 曲情報とシークバーを「まふ」の横へまとめ、縦幅を抑えたプレーヤーへ刷新
- 前の曲、再生・一時停止、停止、次の曲を押しやすいサイズへ拡大
- ファイル名の重複表示をなくし、シークつまみの端が欠ける表示を修正

Android 10以降に対応します。広告、解析、外部通信はありません。
