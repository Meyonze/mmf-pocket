# 高音域のクリップ正弦波キャリア（r71）

modern FMのWS8・9・10について、変調もフィードバックもない最終出力に限って
高音域の折り返しを低減します。既存の波形モデルのクリップ倍率1.7は保持します。
この倍率や形状を、メーカー音源に校正する変更ではありません。

## 残す成分

`g(θ) = clamp(1.7 × sin(θ), -1, 1)`とし、`α = asin(1/1.7)`とします。
連続波形の基音係数と半波整流時の平均値は次の積分から求めます。

- 基音係数 `b = 2/π × (1.7α + cos(α)) ≈ 1.1954300948071888`
- 半波の平均 `d = 1/2 - α/π + 1.7(1-cos(α))/π ≈ 0.40334595618727476`

| 波形 | DC | 残す基音 | 滑らかに移行する範囲 |
| --- | --- | --- | --- |
| WS8：g(θ) | 0 | b × sin(θ) | Fs/6〜Fs/5 |
| WS9：max(0, g(θ)) | d | b/2 × sin(θ) | Fs/4〜Fs/3 |
| WS10：abs(g(θ)) | 2d | なし | Fs/4〜Fs/3 |

WS8は奇数倍音だけなので、第3倍音の上限を超えるFs/6から処理します。
WS9・10は第2倍音の上限を超えるFs/4から処理します。範囲より低い音は
元のfloat丸めを保持します。ビブラート・MULTI・detuneを含む実際の位相増分を使い、
r69の瞬間的なナイキスト抑制も維持します。

基音係数bは1より大きくなりますが、元の波形の基音を積分した値です。
ここを1に切り詰めて振幅を変える処理は加えません。既存の全体ミックス・音量曲線・
最終リミッターは保持します。波形のDCをゼロにする処理も加えません。

既存の正弦テーブルを使い、音ごとのフィルター状態やメモリ割り当ては追加しません。
変調器・フィードバック・従来プロファイルは対象外で、キャッシュをr71に更新します。

## 検証

`tools/fm-clipped-sine-carrier-test.cpp`は、各波形を262,144点の中点積分で測り、
補正関数を使わずにDC・基音の正弦係数・余弦係数を求めます。その基準に対して、
3波形・2レート・13周波数・5初期位相の390条件を確認しました。
完全移行後の最大RMS誤差は約2.35e-7でした。低・中音域の完全一致、全8接続、
変調・フィードバックの除外、ビブラート、ピッチ変更、周期端点も検査しています。
修正前は高音域のDC・基音の一致検査が失敗しました。

既存797素材はWAV全体が一致しました。新しい186素材では対象78素材だけが変わり、
108対照は完全一致しました。合計983素材中905素材が一致し、全素材の形式と
フレーム数を保持しました。r69のビブラート復帰とr70の整流正弦波も維持しています。

`tools/generate-clipped-sine-probes.py <新規ディレクトリ>`で新しい186素材を
生成できます。自作音色だけを使い、全8接続、低音対照、移行域、完全移行後の音程、
変調器、フィードバック、ビブラート、補正域をまたぐピッチ変更を含みます。

クリップ正弦波、整流正弦波、FM位相、既存FM帯域制限、高周波ビブラート、PCM16/JNI
ブリッジ、無音音符の同時発音、入力保護の8スイートがASan/UBSan付きで通過しました。
ローカルのクラウドでは`ASAN_OPTIONS=detect_leaks=0`でリーク検査を無効にしています。
Androidの3 ABIのDebug・Releaseビルドとlintも通過しています。

移行域では元の形状と基準波形の両方を計算します。Android実機の負荷・消費電力は
未測定です。残る波形、低・中音域、動的なFM変調・フィードバックの折り返しや、
メーカー音源との音色校正は引き続き別の課題です。

r71のコミット`3d6a7e7`は[GitHub Actions全体](https://github.com/Meyonze/mmf-pocket/actions/runs/42065711794)も通過しました。
