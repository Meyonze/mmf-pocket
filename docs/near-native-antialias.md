# 等速直上の折り返し低減（r67）

modern PCMの進行比が1より大きく1.1未満の場合に、64タップの低域通過処理を加えます。
r66で改善した等速・小数位置の振幅を保持し、出力ナイキスト直近に残った折り返しを
限られた範囲で低減します。メーカー音源のフィルターを再現する変更ではありません。

## 適用範囲とメモリ

- 1〜1.02で32タップから64タップへ滑らかに移行します。
- 1.02〜1.05は64タップを使います。
- 1.05〜1.1で従来の32タップへ滑らかに戻します。
- 等速以下・1.1以上と従来プロファイルは、従来の処理を保持します。

専用テーブルは遮断周波数の列58〜64だけを保持します。64タップ・128分割位相の
共有領域は231,168B（約226KiB）です。256KiB以下の静的検査も入れています。
既存テーブルの寸法や音源ごとの永続領域は増やしません。必要なテーブルは発音準備時に
初期化します。ゲート、元波形の位置、ループ座標、EOF、発音の割り当て規則は保持します。
既存の最大63サンプルの履歴で扱えるため、無音ループの終了上限も延ばしません。
変換キャッシュはr67です。

## 合成信号の測定

元波形は振幅12,000のPCM16正弦波です。0.499周期/ソースサンプルの入力を
8,192フレーム測り、r66と比較しました。いずれも入力周波数と進行比の積が0.5を超えるため、
出力に残る電力は主に折り返し成分です。波形境界を含まない補間単体の測定で、
プレーヤーの最終フィルター・PCM16量子化・聴感を含みません。

| 進行比 | r66からの折り返し電力低減 |
| --- | ---: |
| 1.01 | 0.65dB |
| 1.02 | 3.16dB |
| 1.05 | 12.98dB |
| 1.08 | 3.61dB |

通過帯域の0.125・0.25・0.4周期/ソースサンプルも別に測り、同じ4進行比での
振幅比は解析的な正弦波に対して0.99116〜1.00001でした。通過帯域の振幅も確認しています。
振幅・位相を変えた48条件の検査、独立した64タップの直接計算、移行境界も検査しています。

## ファイル全体の比較

既存303素材では、この進行比を含む10素材だけが変わり、293素材はWAV全体が一致しました。
新しい54素材では対象41素材だけが変化し、13対照は完全一致しました。
合計357素材中51素材が意図した変更、306素材が一致しています。全素材で形式・フレーム数を
保持しました。前回の「音程を戻した後」の2素材は、30ms以降の比較区間のPCMも完全一致し、
振幅改善を維持しています。

`tools/generate-near-nyquist-probes.py <新規ディレクトリ>`で54素材を生成できます。
PCM楽器、Mobile/MA-7の録音Audio、通過帯域と折り返し帯域、短いループ、
等速・進行比1.1の境界、適用範囲外の音高、音程を戻すケースを含む自作単音です。

ASan/UBSan付きの音声回帰、高比率変換、録音Audio、ATR、PCM16出力ブリッジ、
入力保護の6スイートが通過しました。クラウドではリーク検査を無効にした
`ASAN_OPTIONS=detect_leaks=0`で実行しています。Android 3 ABIのDebug・Releaseと
lintも通過し、lintはエラー0件・既存警告4件です。

## 負荷と残る範囲

対象範囲は従来よりタップ数が増え、移行域では32・64タップの両方を計算します。
Androidの処理時間・消費電力は未測定です。等速以下・1.1以上に適用を広げる判断はしていません。

ナイキスト周波数に極端に近い成分や1に極めて近い進行比では、有限長フィルターの
遷移帯域が残ります。全周波数での折り返し除去を保証するものではありません。
長いフィルターによる過渡応答の違いと、端末負荷の確認も今後の項目です。
