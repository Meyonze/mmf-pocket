# 実際のプレイヤーで定常FMの折り返しと音量を測る

`tools/fm-player-sideband-audit.cpp`は、独自のVM5音色定義とMobileシーケンスを
公開APIの`MaPlayer`へ渡し、実際の合成・ミックス・FIR・出力ローパスを測ります。
内部状態を読み戻さず、固定したソフトウェアモデルのPM式・Bessel係数と、独立した
FIRの周波数応答から基準を求めます。旧端末や他アプリの再現度の測定ではありません。

## 条件と出力

音程60・72・84・96、キャリア/変調器の倍率2/3・5/7、変調器TL0・24・36の24音色条件です。
2演算器の正弦波直列、フィードバック・AM/VIBなし、最大ベロシティと音量、持続中のEGを使います。
各音色で通常経路、72フレームの遅延対照、2/4/8/16/32倍のExact/Hermiteを比較し、計288条件を出力します。
ウォームアップ512フレーム後の1,024フレームを、既知の遅延に合わせて比較します。

参照値は、現在のVM35モデルのPM深度4、TL1段0.75dB、ミックス0.32、二段の出力ローパスなどを
明示的に固定しています。レガシーのハード左パンの左2・右0も含み、MA7のcos/sinパンとは分けています。
将来ソフトウェアの音量則を意図的に変更するときは、その根拠とともに参照値を見直す必要があります。

| JSONの項目 | 意味 |
| --- | --- |
| `full_equation_error_rms` | 有限FIR・ローパスを含む独立計算と、実際のプレイヤーとの差 |
| `ideal_band_error_rms` | Nyquist以上の成分を除いた基準との差。有限FIRの通過帯域・境界の誤差も含む |
| `output_rms` | 測定窓の実際の出力音量 |
| `rms_change_db` | 通常経路に対する音量変化。減った電力を戻す補正は行わない |
| `math_delta_rms` | 同じ倍率でのExact/Hermiteの差 |

フィルター適用前に基準音量へ揃える処理は加えません。無変調・変調・高音域や過渡応答は
異なる課題であり、この定常正弦波の結果から全曲への倍率を自動選択しません。

## 今回確認できた例

キャリア倍率5・変調器倍率7・TL0、Exactの一例です。誤差は正規化floatのRMSです。

| 音程 | 通常経路の理想帯域との誤差 | 8倍 | 16倍 | 32倍 |
| --- | --- | --- | --- | --- |
| 84 | 約0.2045 | 約1.02e-5 | 約1.05e-5 | 約7.62e-6 |
| 96 | 約0.1957 | 約0.0969 | 約8.49e-6 | 約6.75e-6 |

同じ音色でも、1オクターブ上では8倍に大きな折り返しが残る例を確認しました。
音程84の8倍処理では約11.4dB、音程96の16倍では約14.1dB、通常経路よりRMSが下がっています。
これは除いた成分による変化であり、楽器ごとの音量校正ではありません。実曲のパート間バランスと
端末の処理量を合わせて検討する必要があります。

全288条件の独立した有限FIR・PM式との差は、今回のホスト測定では最大RMS約7.94e-8でした。
倍率を上げた場合の理想帯域との差は、有限フィルターの特性によって単調には変化しません。
単一の高音素材や、定常側帯波の上限だけで全音源の倍率を決めないための診断です。

## 実行

```sh
mkdir -p build/fm-player-sidebands
c++ -std=c++20 -O2 -Ithird_party/yamaha-smaf-player/src tools/fm-player-sideband-audit.cpp build/native-render/libsmaf.a -o build/fm-player-sidebands/audit
build/fm-player-sidebands/audit --self-test
build/fm-player-sidebands/audit > build/fm-player-sidebands/report.json
python3 tools/fm-player-sideband-audit-cli-test.py --binary build/fm-player-sidebands/audit
```

4件のCLI検証は、24音色・288設定の構成、独立計算との誤差、遅延対照の一致、
高音域で8倍に残る折り返し、音量変化、方式の差と不正引数を確認します。ReleaseとASan/UBSanで通過しました。
音の立ち上がり、動的なEG/LFO、フィードバック、直列4演算器、内蔵ROM音色、端末での性能は
この診断の対象外です。通常再生・変換キャッシュr82・正式版1.6.6は変更しません。
