# 残る固定波形キャリアの高音域（r73）

modern FMのWS7・14・17〜22・25〜30について、変調もフィードバックもない
最終出力に限り、高音域で元の形状から連続波形のDC・基音へ滑らかに移行します。
低・中音域は元のfloat丸めを保ち、音符時刻・ゲート長・全体の音量曲線は保持します。
音色間の音量校正やメーカー波形の再現精度を保証する変更ではありません。

## 係数と適用範囲

θを演算器の位相とし、出力を `DC + S sin(θ) + C cos(θ)` で表します。
`T = 8(√2−1)/π²` です。

| WS | DC | S | C |
| --- | --- | --- | --- |
| 7 | 0 | 2/π−12/π³ | 0 |
| 14 | 1/2 | 2/π | 0 |
| 17 | 1/4 | 4/π² | 0 |
| 18 | 1/2 | 0 | 0 |
| 19 | 1/4 | 0 | 0 |
| 20 | 0 | 0 | T |
| 21 | 1/4 | T | 0 |
| 22 | 1/2 | 0 | 0 |
| 25 | 1/4 | 1/π | −2/π² |
| 26 | 1/2 | 0 | 0 |
| 27 | 1/8 | 0 | 0 |
| 28 | 0 | 0 | 2/π−4/π² |
| 29 | 1/4 | 1/π | 1/π−4/π² |
| 30 | 1/4 | 1/π | 1/π |

WS14は奇数倍音の第3倍音が上限を超えるFs/6からFs/5へ、その他は第2倍音が
上限を超えるFs/4からFs/3へ移行します。三次smoothstepで境界をつなぎます。
WS30はmodernの1/4周期パルスです。従来プロファイルの半周期パルスと混同せず、
独立した参照計算も公開演算器の出力を使います。

共有係数表は1KiB、正弦計算は既存の共有テーブルを使います。音別の状態や
メモリ割り当ては加えません。実際の位相増分で適用域を選び、r69の瞬間的な
ナイキスト抑制も維持します。キャッシュはr73です。

これで実装済みの固定波形について、高い無変調最終出力の対策が揃いました。
WS15・23・31の未対応ユーザー波形、低・中音域、変調・フィードバック、移行域に
残る折り返し、元の音色モデルの校正は引き続き別の課題です。

## 検証

`tools/fm-remaining-carrier-test.cpp`は各形状262,144点の中点積分でDCと正弦・余弦
係数を求めます。14形状・2レート・13周波数・5初期位相の1,820条件で、
完全移行後の最大RMS誤差は約1.31e-7でした。低・中音域の完全一致、全8接続、
変調とフィードバックの除外、ビブラート、ピッチ変更、周期端点も確認しました。
修正前は高音域のDC・基音の一致検査が失敗しました。

既存1,253素材はWAV全体が一致しました。新しい868素材では対象276素材だけが変わり、
592対照は完全一致しました。合計2,121素材中1,845素材が一致し、全素材の形式・
フレーム数を保持しました。メーカー音色やROMを含まない自作素材です。
`tools/generate-remaining-carrier-probes.py <新規ディレクトリ>`で再生成でき、
868素材とマニフェストは再生成時もバイト単位で一致しました。

固定波形・ゲート正弦波・クリップ正弦波・整流正弦波・FM位相・既存FM帯域制限・
高周波ビブラート・PCM16/JNIブリッジ・無音音符の同時発音・入力保護の10スイートが
ASan/UBSan付きで通過しました。ローカルのクラウドでは
`ASAN_OPTIONS=detect_leaks=0`でリーク検査を無効にしています。
Androidの3 ABIのDebug・Releaseビルドとlintも通過しました。実機負荷・消費電力は未測定です。
