# r93：MA7のリバーブ送り（CC91）に汎用リバーブを適用

## 変更内容

MA7譜面のCC91（リバーブ送り）を、これまでの「未対応」から、チャンネルごとの送り量として
扱うようにしました。各発音の出力に、そのチャンネルの送り量（0〜127を0〜1に換算）を掛けて、
共有の汎用リバーブへ送ります。リバーブの戻りは、出力フィルターとリミッターの手前で足します。

- 対象はMA7（Format 3）の譜面だけです。Mobile形式のCC91は、これまでどおり未対応です。
- 送りが0、または設定が無い譜面は、リバーブの処理を飛ばします。出力は、変更前と
  1ビットも変わりません（テストで確認）。
- 曲末では、リバーブの尾が小さくなるまで描画を続けます（既存の上限は超えません）。
- 診断では、CC91を「部分対応（Partial）」として数えます。実機の効果ではなく、近似だからです。
- 変換キャッシュは `r93-ma7-reverb-v1` です。
- CC93（コーラス送り）は、今回も未対応です（下記）。

リバーブは `ma_effects.h` の、8本の遅延線とHadamard行列によるFDN（遅延フィードバック網）です。
入力側に2段のオールパス、反響時間60 dBが1.6秒、高音の減衰係数0.2、プリディレイ12 ms、
戻りの強さは2.0です。左右で別々の出力を取るので、左右の相関が下がります。
これらは、実機の効果ではなく、1曲の外部録音との比較で選んだ近似値です。

## 根拠と測定

同じ編曲の外部録音1つと比べると、こちらの出力は左右がほぼ同じでした
（左右の相関が、500 Hz〜8 kHzで0.87〜0.88。録音は0.34〜0.66）。また、録音には、中低域に
100 ms以上続く響きがありました（エネルギー領域の分解による。楽器の余韻の違いも混ざるため、
残響時間はこの解析だけでは決められません）。

MMFが設定している送り量は、曲の先頭に1回だけで、チャンネルごとに、リバーブ20〜80、
コーラス0〜25でした。

| 条件 | 左右相関の誤差 | 側／中の比の誤差 | 高音の偏り | 帯域バランスの誤差 |
| --- | --- | --- | --- | --- |
| 効果なし | 0.262 | 2.19 dB | −1.7 dB | 1.07 dB |
| リバーブ（採用：1.6秒、強さ2.0） | 0.132 | 1.74 dB | −1.6 dB | 1.18 dB |
| リバーブ（3.0秒、強さ1.0） | 0.153 | 1.46 dB | −1.6 dB | 1.13 dB |

誤差は、録音との、帯域ごとの左右相関（8帯域）の平均差、側／中のエネルギー比（dB）の平均差です。
音のバランス（高音の偏り、帯域バランス）は、ほぼ変わりません。響きだけが足されています。
残響時間1.6秒と3.0秒の差は、この測定では、はっきりしませんでした。

### コーラスを入れなかった理由

リバーブに、コーラス（2本の変調遅延）を足して試しましたが、左右相関の誤差は
0.132から0.130に、ほとんど変わりませんでした。測定で効果を示せないので、入れていません。

## 限界

- 参照は1曲だけです。録音の音源は、実機録音か別のソフトかも、分かっていません。
- 録音の左右相関は、500〜2000 Hzでなお低く（0.34〜0.54）、このリバーブでは、そこまで
  下がりません（0.65〜0.73）。録音側に、チャンネルごとの左右の広がりなど、別の仕組みが
  ある可能性があります。
- 効果の強さの換算（送り量から戻りまで）は、1曲に合わせた値で、実機の仕様ではありません。
- 全体の音量が、約3 dB上がります（リバーブが足すエネルギー）。音量の補正は、入れていません。
- 聴感での確認は、ここでは行っていません。

## テスト

`tools/ma7-reverb-regression.h`（`audio-regression` から実行）が、従来の描画経路とアプリの経路の
両方で、次を確認します。

- 送り0は、送りなしとビット単位で同一。
- 送りがあると出力が変わり、左右が別々になる。出力は有限。
- ブロック幅1・257・1024で同一。シークし直しても同一。
- 描画が終わるまでに尾が消える。リバーブは描画を短くしない。
- 送りが大きいほど、リバーブが増える。
- Mobile形式のCC91は、無視される。

## r95：送りの低音をカット

r93のリバーブは低音にも広がりを足し、60〜250 Hzの左右の相関が録音より低くなっていました
（録音0.86/0.82/0.74、こちら0.70/0.81/0.60）。リバーブへ送る信号に、1次のハイパスを入れました。

| 送りのハイパス | 左右相関の誤差 | 側／中の比の誤差 | 帯域バランスの誤差 |
| --- | --- | --- | --- |
| なし（r93） | 0.136 | 1.86 dB | 1.05 dB |
| **150 Hz（採用）** | 0.120 | 1.56 dB | 1.12 dB |
| 300 Hz | 0.115 | 1.68 dB | 1.12 dB |
| 600 Hz | 0.125 | 1.70 dB | 1.14 dB |

（測定はr94の描画が基準です。）1曲の録音との比較で選んだ値です。変換キャッシュは `r95-reverb-hp-v1` です。
テストに、低い音はリバーブで左右に広がりにくいことの確認を加えました。
