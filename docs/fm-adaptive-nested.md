# 強い直列FMの選択的な高倍率処理

固定16/32/64/128倍の実MMF経路に続き、対象音の周波数から倍率を選ぶ実験経路を追加しました。
通常のアプリ初期化、キャッシュr91、正式版1.6.6は維持しています。

```sh
smaf-render input.mmf output.wav 30 --experimental-adaptive-nested
render-contribution-audit input.mmf 30 --experimental-adaptive-nested
```

C++では`SineRenderOptions{8, FmSubframeMath::Hermite, true, false, true}`です。
フラグ単体で方式を指定し、固定倍率・数式方式・固定nested・app-qualityとの併用と重複は拒否します。
寄与診断は`adaptive_nested: true`と32/64/128倍を含むカウンターを出し、実レンダラーと照合します。
既存のレポートの形式は維持します。

## 初期対象と倍率

従来の8/16倍方針を先に維持します。新たに加えるのはmodern VM35の4演算器・接続6、
全正弦波、実効フィードバック・固定周波数・MA7 Detuneなし、両変調器のTLが12以上、
演算器1/2/3の設定上のアタックが非ゼロの音です。ビブラート付きの音も含みます。
従来対象の弱いVM35、MA7、他の接続や対象外の音は従来経路へ残します。
これは端末間の音色互換性を確定する分類ではありません。

新しい対象では、各変調器のTLを12/16/20/24以上の4段階へ切り下げ、それぞれの変調指数を
9/6.5/4.5/3.2以下で包みます。両変調器の組み合わせと最大演算器周波数から倍率を選びます。
例えばTL12/12では、出力レートに対する最大周波数が1/16以下で16倍、1/8以下で32倍、
17/64以下で64倍、それ以上で128倍です。TL20/20では11/64まで16倍、22/64まで32倍を使えます。
既存のnative Nyquist抑制を保ち、0.5以上の演算器はそのまま抑制します。
ビブラートは、基準周波数に`1 + abs(固有の深さ × 倍率)`を掛けた全周期の上限で包みます。
プレイヤー内の倍率は0〜8、固有の最大深さは0.01548なので、最小周波数も基準の0.87616倍以上です。
発音中の倍率は上昇だけに限定し、再発音で初期化します。ピッチ・ビブラート強度の変更を次のフレームから反映し、
揺れの瞬間値を使って毎フレーム倍率を上下させることはありません。
通常のプレイヤーが生成する有限・非負のピッチが前提です。公開コアAPIのビブラート倍率は有限の[-8,8]を対象にします。
有効なビブラートを持つ音が開始時にこの範囲外なら、その発音は従来の経路を維持します。
高倍率の経路へ入った後の範囲外入力では128倍を維持し、音をミュートしたりnativeへ戻したりしません。
範囲外の公開API入力に対する音質上限は保証しません。

64通りの閾値は、独立周波数の解析的な絶対係数和の上限をfactor-0.5で計算し、1e-4以下と検証します。
重い探索をレンダリング中に実行せず、対象の判定・表の参照・周波数比較だけを使います。
この定常モデルの上限は、LFO・EG・コントローラーを含む非定常スペクトル全体や、FIR後の全誤差を保証するものではありません。

## 履歴と検証

従来の8/16倍バスに加え、実験時だけ32/64/128倍バスを初期化します。
すべて72フレームの遅延へ揃え、音が移った旧バスはゼロ入力で余韻を出し切ります。
PCM・ATR・録音Audioは一度だけnative遅延へ通します。曲末は全バスの有限余韻と既存LPを待ち、
ハード上限は従来どおり72フレームを加えた境界でフェードします。
通常経路の32要素の作業領域は維持し、大きな作業領域は実験用のテンプレート実体だけが使います。

実プレイヤーの16→32→64→128倍、下降ピッチ、余韻の重なる再発音、音量ゼロと微小音量からの復帰、
Holdと解放を、別実装の音源と密なFIR畳み込みで照合しています。
曲末・1/17/1024フレームのブロック・シーク・再初期化・不正初期化の原子性・3種類のハード上限、
4倍率同時発音とPCM/ATR混在の寄与診断も検査します。
4,608条件でビブラート全周期の正の周波数と上限を照合し、強度変更だけによる3種類の昇格、
範囲外入力の開始時と発音中の扱いも検査しています。ビブラートとAMを含むExact/Hermiteの実出力を、
独立した音源・密なFIR畳み込みと照合しました。実際のCC1、リセット、Hold、キーオフとPCM/ATR混在でも
16→32倍の移動と寄与カウンター、ブロック幅の異なる参照プレイヤーとの一致を確認しています。
24種類の既存ファミリー・接続の出力は従来方針とビット一致しました。
自作MMFの8構成とビブラート付き4構成では、変調器ごとの強さの違いも含め、選択された倍率の固定モードと実WAVが完全一致しました。
VM35設定とFormat3 CC1を持つ自作MMFでも、16→32倍の移動、固定32倍への収束、入力の不変性と診断の一致を確認しました。
これらはソフトウェア内の検査で、実機チップでの形式互換性の検証ではありません。

## 残ること

高倍率の多重発音はまだ重く、端末上の速度・電力は未測定です。
今回の閾値も保守的な初期設定です。過渡での実質的な折り返し量、
実ファイルの音色バランスと端末音源との比較を続けてから、通常アプリへの適用を判断します。
EOFやフィルターの履歴が正しいことと、聴感上の完全な再現は別の検証です。

実験経路の[位相計算の除算を軽量化](fm-nested-reciprocal.md)しています。倍率方針や補間精度は維持しています。
