# FM矩形波・のこぎり波の折り返し低減試作

**追記（r60）:** 下記は広範囲へ補正する最初の試作記録です。その後の複数演算器の検証で
誤差が増える経路が見つかり、採用実装は「変調を受けず、自己フィードバックもない最終出力」
だけに限定しました。補正係数は共有表とキャッシュで軽くしています。
現在の実装と検証は[音質の現在地](audio-quality-ja.md)と[DSP記録](dsp-review.md)を参照してください。

2026-10-30、r59を基準に、PolyBLEPによる不連続点の補正を試しました。
比較用のコードだけを `build/fm-blep-prototype` に保存し、アプリの再生コード・
APK・キャッシュ版は変更していません。別プレーヤーや旧端末の再現度を示す実験ではありません。

## 比較した案

- 単純補正: modernプロファイルのWS6・WS24にだけ、発振器の1サンプル当たりの
  位相増分を幅とした二次式の補正を加えます。WS24の不連続点は半周期の位置です。
- 振幅補正付き: 上記を `sinc(π × 位相増分)²` で割り、変調のない基音の減衰を補います。
  この試作は毎サンプル正弦計算を行うため、処理量が増えます。

ここで `sinc(z)=sin(z)/z` とします。補正は位相増分が0より大きく0.5未満の場合だけ
適用します。既存のナイキスト抑制は保ちます。外部位相変調の瞬間的な速度を使う案ではなく、
位相変調下での正しさをこの式だけから仮定していません。

## 参照信号と結果

44,100 Hz、2,048サンプルの周期信号です。発振器は4,096サンプル進めてから測ります。
2波形 × 基音3ビン（17/127/401）× 変調3ビン（31/257/911）×
位相変調6深度（0/0.02/0.25/1/4/8周期）の108条件を比較しました。
深度0では変調周波数が結果に影響しないため、独立した信号は96種類です。

参照は、同じ連続時間の矩形・のこぎり波と正弦位相変調を32倍・64倍の密度で標本化し、
FFTで出力ナイキスト未満に帯域制限したものです。時間領域の平均二乗誤差に対応する
全ビンの差分電力を計算し、DCも含めます。参照の出力ナイキストビンは除外します。
これは有限密度の近似であり、無限精度の理想波形や実機録音ではありません。

変調無しの6信号について、64倍参照に対する二乗誤差の低減は次のとおりでした。

| 案 | 誤差低減率の範囲 | 基音への影響 |
| --- | ---: | --- |
| 単純補正 | 約80〜90% | 約8.6kHzで、基準出力より約1.11dB減衰 |
| 振幅補正付き | 約81〜95% | 上記の定常基音の減衰を補償 |

108条件すべてで、両試作の測定した二乗誤差は基準より小さくなりました。
変調のある条件では改善幅が小さいものもあり、誤差比の最大値は約0.986でした。
参照32倍→64倍の差の電力は、最大で基準の誤差電力の約1.5%です。
改善幅が最も小さい6条件を64倍→128倍でも確認し、誤差比の最大値は
単純補正で約0.9860、振幅補正付きで約0.9864でした。
有限密度での参照収束確認であり、全条件の厳密な誤差上限ではありません。

この結果は聴感上の改善率や全折り返し電力の低減率ではありません。
実際の複数演算器の接続、自己フィードバック、発音開始、最終ミックス・フィルター・
リミッター、PCM16、Android経路は、この参照比較に含みません。

## 処理負荷と判断

同じホストCPUに固定し、32個の発振器、32,768フレーム、ビブラート有無で
各案を交互順に5組測りました。初期化・4,096フレームのウォームアップは計時外です。

| 対象WS6/WS24 | 基準に対する処理時間の中央値比 |
| --- | ---: |
| 単純補正 | 約1.25〜1.37倍 |
| 振幅補正付き | 約1.67〜1.99倍 |

これはホスト上の探索的測定で、アプリ全体やAndroidの処理時間ではありません。
音声が同一のWS0対照も約0.82〜1.06倍に揺れており、均一な速度比を保証できません。
それでも対象波形で追加処理が大きく、**両案とも現段階では常時適用しません**。
次は、毎サンプルの正弦計算を避ける補正係数の表引きなどを試し、ビブラートや音程変更を
含む精度・処理時間を比較します。音を消したり全体を弱めたりして指標を下げる案にはしません。

対象外の経路は、32波形・2プロファイル・3音程・AM/VIB有無・位相変調有無の
768組で調べました。各512サンプルの途中で音程も変え、各案につき対象外の
380,928個のfloat出力が基準とビット一致しました。対象波形の12,288個は一致対象に含めません。
これは列挙したソフトウェア条件の確認で、全入力・全端末での保証ではありません。

## 再実行

検証ZIPには凍結した基準・2試作のコア、ヘッダー、元のスペクトル測定ツール、
実験・負荷・経路比較のソースと生JSONを収録しています。ルートに展開して、例えば次で
振幅補正案を再測定できます。実行結果は新しいファイルに保存してください。

```sh
c++ -std=c++20 -O2 -Wall -Wextra -Werror \
  -Ithird_party/yamaha-smaf-player/src \
  build/fm-blep-prototype/experiment.cpp \
  build/fm-blep-prototype/ma_fm_core-compensated.cpp -o /tmp/mmf-blep-experiment
/tmp/mmf-blep-experiment > /tmp/mmf-blep-experiment.json
```

`refine.cpp` は改善幅の小さい6条件の高密度参照、`benchmark.cpp` はホスト負荷測定、
`trace.cpp` はfloat列の出力です。通常のアプリビルドには含めません。
