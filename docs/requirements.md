# MMF Pocket 要件

## 対応環境

- Android 10（API 29）以降
- 画面回転後もクラッシュせず、権限が残っていれば保存済みフォルダを再読込できること

## ストレージとプライバシー

- AndroidのStorage Access Frameworkでユーザーが選択したフォルダだけを読み取る
- ストレージ全体への権限を要求しない
- MMF、ファイル名、変換音声をネットワーク送信しない
- 変換WAVはアプリのプライベートキャッシュへ保存する
- 1ファイル16MB、変換キャッシュ512MBを上限とする

## 再生

- 選択フォルダ直下のMMFとサブフォルダを表示し、フォルダをタップして階層を移動できる
- MMFを一覧表示し、選択時にWAVへ変換して再生する
- 再生、一時停止、停止、シーク、現在のフォルダ内の一括変換に対応する
- アプリがバックグラウンドへ移動した後や画面消灯中も再生を継続できる
- 通知とロック画面から再生、一時停止、停止、シークを操作できる
- Bluetooth機器とイヤホンのメディア操作を受け付ける
- Audio Focusの喪失時に一時停止し、一時的な喪失からの復帰時だけ再生を再開する
- Activityの再表示時に現在の曲、再生状態、再生位置、変換済み範囲を同期する
- フォルダ内一括変換はバックグラウンド処理の対象に含めない
- MA-1/2/3/5とMA-7 Format 3のスコアを対象とする
- 10/20/40/50msを含むSMAF時間単位を正しく扱う
- VM35の有効な29オペレーター波形を個別に扱う
- 端末ROM音色が利用できない場合はROMフリーのFM近似音色を使用する
- 「携帯スピーカー風」は小型スピーカーの出音を模す汎用後処理とし、特定端末や音源ROMの再現とは表現しない

## 配布

- GitHub Releasesで署名済みAPKを配布する
- APKのSHA-256と署名証明書のSHA-256フィンガープリントを掲載する
- MMFサンプル音源および生成WAVを配布しない
