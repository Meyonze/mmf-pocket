# r92：MA7のFM変調の深さを4サイクルへ

## 変更内容

全演算器がMA7形式（`ma7Multipliers`）のFM音色について、位相変調の深さを
0.42サイクルから4.0サイクルへ変更しました。VM35形式がすでに使っている値と同じです
（出力2^13・位相シフト2^15・位相周期2^26から導かれる4サイクル。`ma_fm_core.cpp`）。
MA7と他形式が混在する設定、互換形式、MA3/5は、これまでどおり0.42です。

折り返し対策（16倍処理）の対象も、深さに合わせて見直しました。r91はMA7の変調が
最大0.42サイクルであることを前提に、TL0〜63すべてを16倍の対象にしていました。
深さが同じになったので、VM35（r90）と同じ「変調器1・2のTLがともに24以上」に
そろえました。TLが24未満のMA7は、VM35の強い変調と同じく、通常の経路で処理します。
変換キャッシュは `r92-ma7-pm4-v1` です。

## 根拠と測定

実在するMA7のMMF1曲と、同じ編曲の外部録音を、時間を揃えて比べました。
オンセット（音の出だし）の相関は0.63で、区間ごとのずれは0.00秒でした。同じ譜面・同じテンポです。

比較では、全体の音量差（こちらが約12 dB小さい）を除き、周波数帯ごとの偏りだけを見ています。
音量の補正は加えていません。外部録音は60 Hzから16 kHzを8帯域に分けて比べました。

- 旧値（0.42）では、1 kHz以上の帯域が、低域に対して録音より約6〜7 dB少ない。
- この偏りは、ROM音色の代わりを使っていないチャンネルだけが鳴る時間帯でも出た
  （ROM代替の寄与ではなく、FM合成全体に共通する差）。
- MA7の変調の深さだけを変えて描画し直すと、次のとおりでした。

| 深さ | 高音の偏り（前半／後半） | 帯域ごとの誤差（前半／後半） | 帯域ごとの相関（前半／後半） |
| --- | --- | --- | --- |
| 0.42（旧） | +7.6 / +5.9 dB | 4.45 / 4.47 dB | 0.558 / 0.513 |
| 1 | +6.4 / +5.4 dB | 4.04 / 4.08 dB | 0.589 / 0.531 |
| 2 | +3.3 / +2.9 dB | 3.60 / 3.59 dB | 0.606 / 0.566 |
| 3 | −0.2 / +0.1 dB | 3.52 / 3.51 dB | 0.595 / 0.571 |
| **4（採用）** | −2.5 / −1.4 dB | 3.52 / 3.73 dB | 0.576 / 0.528 |
| 6 | −5.2 / −3.3 dB | 3.85 / 4.08 dB | 0.514 / 0.459 |

「高音の偏り」は、1 kHz以上と1 kHz未満の、録音に対するレベル差の平均です（0に近いほど近い）。
「帯域ごとの誤差」は、帯域ごとの音量を揃えたうえでの、時間ごとのレベル差の平均です。
曲の前半と後半で、同じ傾向でした。

## 限界

- 参照は1曲だけです。ほかのMA7曲で同じ傾向かは、測っていません。
- 外部録音の音源（実機録音、別のソフト、動画側の加工）は分かりません。
  測ったのは、その録音との近さであり、実機への一致ではありません。
- この録音との一致だけを見れば、最適は約3で、採用した4.0は少し明るめです（−1〜−2.5 dB）。
  3を採らなかったのは、1曲に合わせ込んだ値になるためです。4.0はVM35と共通の基準で、
  測定した最適な範囲（2〜4）に入っています。
- 聴感での確認は行っていません。ほかのMA7曲で、音が硬くなる、耳に痛くなるなどが
  起きていないかも、未確認です。
- TL24未満のMA7は、以前は16倍で処理していましたが、今は通常の経路になります。折り返し
  ノイズが増える可能性があります。増える量は測っていません。
- ROM波形の代わりの音色（ピアノ・ストリングス・ハイハットなど）は、今回の変更の対象外です。
  その影響は、重なる音の中から分離できませんでした。

## 更新したテスト

MA7の深さを0.42としていた期待値と基準を、新しい規則に合わせました。緩めたのではなく、
基準側の深さを実装と同じ値にしたものです。TL24未満のMA7が対象外になることの確認も加えました。

- `fm-nested-sine-test`：MA7の独立したBessel基準を深さ4に。TL24未満は対象外であることを確認。
- `fm-feedback-regression.h`、`vm35-modulation-regression.h`：MA7完全セットの基準を深さ4に。
  混在設定が0.42のままであることは維持。
- `render-contribution-audit-test`：MA7の検証設定を、対象内のTLに。

## 確認用

深さを一時的に変えて測るには、環境変数のような仕組みは入れていません。測定に使った
スクリプトはこのリポジトリに含めていません（外部録音を含むため）。同じ手順で再現するには、
同じ編曲の録音を用意し、オンセットで時間を揃えて帯域ごとのレベルを比べてください。
