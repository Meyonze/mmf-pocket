# 置き換えられた録音で余韻が延びる問題（r62）

録音トラック（ATR）の長い音声が同時発音数の制限で置き換えられた後も、
元の波形の予定長が曲末の安全上限に残っていました。別のFM音やサンプル楽器が
長く持続すると、既に再生していない録音の長さだけ余韻が延びる場合があります。

再現素材では16秒の録音が最初のサンプル前に置き換えられ、終了予定が約26秒に
なっていました。実際に残る音源だけを持つ対照素材の約10.01秒まで補正します。
録音を途中まで鳴らしてからサンプル楽器が置き換える場合も検査しています。

## 修正したこと

初期化時は従来どおり、波形の予定長から保守的な上限を計算します。
最後のスコア指示まで処理し、実際に再生中のATR音源がすべてなくなった時点で、
完走した音源の終了予定時刻、本人のゲートで止まった時刻、最後の指示時刻を使って
上限を補正します。置き換えられた音源の未来の予定長を残しません。

判定に音量やRMSは使いません。音量ゼロでもまだ再生中の録音、通常の長い録音、
未来の発音・制御指示は維持します。波形、音程、音量、同時発音の置き換え順、
エンベロープ、従来の10秒の安全余韻と終端フェードは変更しません。
シーク時には初期の保守的な上限と完了履歴を戻し、再生をやり直せます。

各音源の終了予定は既存の `ceil(サンプル数 × 出力Hz / 元のHz) + 1` と同じ規則です。
単に「音源がなくなった現在のサンプル」を採用すると、サンプル変換の累積端数で
44.1kHzの終了位置が1サンプルずれるケースがありました。追加検証でこれを捉え、
元の丸め規則を保つよう修正しています。

## 検証

専用のネイティブ試験では16音/32音の枠、持続するFM/サンプル楽器、8kHz/44.1kHz、
後続の発音・未対応指示、シーク、再初期化、読み取り単位、通常・ミュート中の
長い録音、サンプル楽器が録音を置き換えるケースを検査します。

新しい17個の自作ファイルを加え、158個のMMFを比較しました。既存141個はすべて
同条件のWAVが一致し、対象7個だけで安全余韻と終端フェードの位置が直ります。
残る151個はバイト単位で一致しています。7個すべてが、実際に残る音源だけを
書いた対照、または本人のゲートで録音を止めた独立した対照と完全一致しました。
対象の以前の出力とも、新しい終端フェードが始まるまで一致します。

比較上限は既存素材が12秒、新しい素材が35秒です。新しいケースの約26秒の旧出力と
約10〜12秒の修正出力は、上限に当たらず最後まで比較しています。
素材はソフトウェアの音源枠・寿命の検証用であり、メーカー素材・個人の楽曲を含みません。
実機の音色再現度や他アプリでの受け入れを保証する試験ではありません。

変換済みWAVに以前の余韻が残らないよう、キャッシュをr62へ更新します。
