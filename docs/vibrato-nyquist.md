# ビブラートと高周波抑制（r69）

FM演算器の周波数が出力レートの半分以上になる場合は、既存の再生方針で出力を抑制します。
従来はビブラート前の中心周波数で判定していたため、次の2つのケースがありました。

- 中心周波数は範囲内でも、ビブラートで上限を超えた瞬間の音が出てしまう。
- 中心周波数が上限以上だと、ビブラートで範囲内に戻っても音が出ない。

Mobile/MA-7のmodern FMでは、ビブラートを含む実際の位相増分で判定します。
位相とエンベロープは無音中も進め、範囲内へ戻ったときの時刻と位相を維持します。
HandyPhone等の従来プロファイルと、ビブラートなしの経路は元の処理を保ちます。
音色の接続、フィードバック、LFO深さ・速度、音量曲線は変更しません。

## 曲末の余韻

中心周波数だけを見た無音判定では、曲末後にビブラートで聞こえる音も切っていました。
これからのLFOの全範囲と現在のCC1倍率を使い、最低の位相増分でも上限以上になる場合だけ
周波数を理由に無音と判定します。変調倍率がゼロの場合や、最低周波数も高すぎる音の
不要な無音を延ばしません。極小音量のしきい値による切り捨ては行いません。

## 検証

`tools/fm-vibrato-nyquist-test.cpp`は、8kHz・44.1kHz、従来/modern、EVB有無、
4深度、5倍率、上限付近の4周波数を検査します。163,840サンプルを、
積分した位相と解析的な正弦波に照らして確認します。従来/modernの無音証明、
抑制中のリリース、曲末後の復帰、分割サイズ、シークも検査しています。
修正前は、中心の位相増分0.5、瞬間の増分0.49995で有音に戻れない検査が失敗しました。

`tools/generate-vibrato-nyquist-probes.py <新規ディレクトリ>`で、独自の音色だけを使った
70素材を生成できます。全8接続、Mobile/MA-7、低音対照、高いMULTI、CC1停止、
EVB停止、生きた変調器を含みます。

既存357素材はWAV全体が一致しました。新しい70素材では対象34素材だけが変わり、
36対照は完全一致しました。合計427素材中393素材が一致し、全素材の形式・フレーム数を
維持しました。曲末後の復帰は専用の8kHzスコアで別に検証します。

Androidの3 ABIのDebug・Releaseビルドとlintも通過しました。
lintはエラー0件・既存警告4件です。音声回帰、専用の高周波ビブラート、FM位相、
FM帯域制限、無音音符の同時発音、入力保護の6スイートもASan/UBSan付きで通過しました。
クラウドでは`ASAN_OPTIONS=detect_leaks=0`でリーク検査を無効にしています。
これはメーカー音源の周期精度や、FM変調全体の完全な帯域制限を保証する修正ではありません。
